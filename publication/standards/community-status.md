This is the **EKGF community draft of DPROD 1.1**, developed by the Enterprise Knowledge Graph Forum, a community of the Object Management Group (OMG). It is not an approved OMG specification.

This edition supports community review and implementation feedback before formal standardisation through the OMG Enterprise Knowledge Graph Platform Task Force. The companion OMG submission preview uses the same technical chapters, ontology, shapes and examples from the same repository revision, with submission-specific front matter.

The official published baseline is [DPROD 1.0 beta 2](https://www.omg.org/spec/DPROD/1.0/Beta2/PDF). A future approved 1.1 publication requires an OMG-assigned document number, approval status, release date and authoritative version URL. This draft supplies none of those approval claims.

The legal preamble is retained from this repository without changing its wording. The closing provenance section identifies the exact source commit and generator used for this build. External ontology imports are not fetched implicitly.

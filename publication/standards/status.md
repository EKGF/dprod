This is a documentation draft for the intended DPROD 1.1 publication. It is not an approved OMG standards release. It includes the source-owned formal sections, core vocabulary and shapes, optional Data Contracts profile, and worked examples from this repository revision.

The publisher preface and bibliographic editions imported from 1.0 beta 2 are explicitly marked for 1.1 confirmation. The legal preamble is collected from this repository's existing source without changing its wording. An OMG-assigned document number, approval status, release date and authoritative version URL must be supplied before the release profile can resolve.

The machine-readable vocabulary and examples, narrative fragments, and their Git commit and blob provenance are retained in the documentation KG. External ontology imports are not fetched implicitly.

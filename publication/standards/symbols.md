The following acronyms are used in this specification.

- **DPROD** - Data Product Ontology [[dprod]]
- **DCAT** - Data Catalog Vocabulary [[vocab-dcat-3]]
- **JSON-LD** - JavaScript Object Notation for Linked Data [[json-ld11]]
- **IRI** - Internationalized Resource Identifier [[IRI]]
- **ODRL** - Open Digital Rights Language [[odrl-model]]
- **OWL** - Web Ontology Language [[owl2-quick-reference]]
- **PROV** - Provenance Ontology [[prov-overview]]
- **RDF** - Resource Description Format [[rdf11-concepts]]
- **RDFS** - RDF Schema [[rdf-schema]], [[swbp-xsch-datatypes]]
- **SHACL** - Shapes Constraint Language ([[shacl]])
- **TTL** - Turtle (commonly used serialization for RDF) [[turtle]] [[rdf12-turtle]]
- **URI** - Uniform Resource Identifier [[URI]]
- **W3C** - World Wide Web Consortium

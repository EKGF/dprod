The following acronyms are used in this specification.

- **DPROD** - Data Product Ontology [dprod](https://ekgf.org/dprod/spec/develop/)
- **DCAT** - Data Catalog Vocabulary [vocab-dcat-3](https://www.w3.org/TR/vocab-dcat-3/)
- **JSON-LD** - JavaScript Object Notation for Linked Data [json-ld11](https://www.w3.org/TR/json-ld11/)
- **IRI** - Internationalized Resource Identifier [IRI](https://www.rfc-editor.org/rfc/rfc3987)
- **ODRL** - Open Digital Rights Language [odrl-model](https://www.w3.org/TR/odrl-model/)
- **OWL** - Web Ontology Language [owl2-quick-reference](https://www.w3.org/TR/owl2-quick-reference/)
- **PROV** - Provenance Ontology [prov-overview](https://www.w3.org/TR/prov-overview/)
- **RDF** - Resource Description Format [rdf11-concepts](https://www.w3.org/TR/rdf11-concepts/)
- **RDFS** - RDF Schema [rdf-schema](https://www.w3.org/TR/rdf-schema/), [swbp-xsch-datatypes](https://www.w3.org/TR/swbp-xsch-datatypes/)
- **SHACL** - Shapes Constraint Language ([shacl](https://www.w3.org/TR/shacl/))
- **TTL** - Turtle (commonly used serialization for RDF) [turtle](https://www.w3.org/TR/turtle/) [rdf12-turtle](https://www.w3.org/TR/rdf12-turtle/)
- **URI** - Uniform Resource Identifier [URI](https://www.rfc-editor.org/rfc/rfc3986)
- **W3C** - World Wide Web Consortium

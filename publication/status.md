This is a generated documentation preview, not an approved OMG standards release
or a replacement for the official DPROD specification. Definitions and shape
statements come from the source RDF. The publication date is read from the
ontology's `dct:issued` annotation; rebuilding documentation does not change that
source annotation.

The repository's `develop` branch is the source for this preview. Each build pins
one concrete Git commit and records source paths, blob identities and commit
provenance in its documentation knowledge graph. External ontology imports are
retained as RDF assertions; this preview does not download or reason over them.
